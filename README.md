## 3️⃣ 한학기 동안의 활동 내역

과거의 내가 현재에 어떤 것을 바랐을 지 생각해보고, 그것이 이루어졌는지 실현, 일부 실현, 미실현 3가지로 구분하여 조사해보자.
질문1. 2000년대가 오기 전, 사람들은 어떤 미래를 기대했을까?
1. 집안일 해주는 로봇: 실현됨.
근거: 센서로 집 안을 인식해 청소하는 로봇 청소기가 상용화됨.
2. 공중 자동차: 일부 실현됨.
현재 기술 개발 중. 현재 테스트하며 상용화 준비 중임.
3. 전쟁 로봇: 일부 실현됨.
총을 쏘며 싸우는 인간형 로봇이 아닌 드론이 실제로 전쟁에 활용되고 있음.
4. 뇌 전파 공유(텔레파시): 일부 실현.
생각을 칩을 이용해 기기를 제어하거나, 의사 소통을 가능하게 하는 BCI 기술이 연구하고 있음. 현재 상용화 준비 중임.
5. 우주 택배: 일부 실현
여러 기업에서 우주 택배를 실현하기 위해 연구 중. 일반인이 이용할 정도로 상용화되지 않음.
6. 텔레포트: 미실현.
과학적으로 거의 불가능하여 실현되기 어려움.
7. 타임머신
과학적으로 거의 불가능하여 실현되기 어려움.
8. 하나만 먹어도 배부른 알약: 방향 전환
위고비, 마운자로와 같은 다이어트 주사 등으로 개발됨. 실제로 배부르기 보다, 포만감을 느끼게 하여 다이어트용이나 비만 치료제로 상용화됨.
9. 인공 장기: 일부 실현됨.
심장과 같은 장기를 인공적으로 만들어 수술 등에 쓰임. 아직 면역 반응 등 더 연구되어야 하긴 하지만 상용화되었음.
