## Mission 1. AI와 함께 문제 다시 쓰기

### 1. Before — 초기 문제 정의

> 기존 보행로는 고령자나 장애인 등 다양한 보행자의 이동 특성을 충분히 고려하지 못하여 이동에 불편함이 발생

초기에는 보행 약자가 겪는 이동의 불편함에 집중했지만, 구체적인 사용자와 발생 상황, 해결 이후의 변화가 명확하지 않았다.

### 2. AI Questioning — AI를 통한 문제 구체화

**AI 활용 프롬프트 예시**

> 기존 보행 환경에서 고령자, 휠체어 이용자, 시각장애인 등이 겪는 불편함을 사용자(User), 상황(Context), 문제(Problem), 기대 변화(Value)로 구분하여 분석해 줘. 또한 AI와 센서 기술로 보행 환경을 개선할 방법과 기술적 한계를 제시해 줘

**AI를 활용한 문제 분석**

| 구분 | 분석 내용 |
|---|---|
| User | 고령자, 휠체어·유모차 이용자, 시각장애인 등 이동 지원이 필요한 보행자 |
| Context | 병원, 역사, 환승시설 등 이동 거리가 길거나 보행 환경이 복잡한 공간 |
| Problem | 이동 피로, 단차와 장애물, 복잡한 경로, 재난 발생 시 안전한 이동의 어려움 |
| Value | 개인의 이동 특성과 주변 상황에 맞춰 안전하고 편리한 이동 환경 제공 |

### 3. After — 개선된 문제 정의

> 고령자와 보행 약자가 병원·역사·환승시설 등에서 이동할 때, 기존 보행 환경이 개인의 이동 특성과 주변 위험 상황을 충분히 반영하지 못해 불편함과 안전 문제가 발생한다. 이를 해결하기 위해 AI와 센서 기반의 적응형 스마트 보행 인프라를 제안

### 4. 팀의 검토 및 수정 내용

AI의 분석을 참고하여 단순한 경로 안내 서비스에서 벗어나, 보행 시설 자체가 상황에 반응하는 방향으로 아이디어를 구체화

- 도시 전체의 보행로를 변경하는 대신 이동 지원이 필요한 구간에 모듈형 시설 설치
- AI 기반 상황 판단과 별도의 안전 제어 시스템을 구분
- 개인 맞춤형 AR 경로 안내와 공용 안전 안내를 연계
- 침수 및 재난 상황에서 이동 모듈 정지와 대피 안내 기능 추가

**최종 문제 정의의 핵심**

> 보행자가 정해진 길에 적응하는 것이 아니라, 보행 환경이 사람의 특성과 상황에 맞춰 변화

## Mission 2. AI 아이디어 비교 및 선택

### 1. 아이디어 도출

보행 환경 개선이라는 문제를 해결하기 위해 세 가지 접근 방식을 비교

#### 아이디어 A — AI 맞춤형 보행 경로 안내

AI가 이용자의 이동 특성을 분석하고 스마트폰이나 스마트 글래스를 통해 적합한 경로를 안내하는 서비스

#### 아이디어 B — AI 스마트 횡단보도

센서와 AI를 활용하여 보행자 수, 이동 속도 등을 인식하고 보행 신호 및 안전 안내를 상황에 맞게 조정하는 시스템

#### 아이디어 C — AI 적응형 스마트 보행 인프라

AI와 센서를 통해 보행자의 상태와 주변 환경을 인식하고, 모듈형 보행 보조·개인 맞춤 안내·재난 대응 기능을 연계하는 통합 시스템

### 2. 아이디어 비교 분석

| 평가 기준 | 아이디어 A | 아이디어 B | 아이디어 C |
|---|---|---|---|
| 필요성 (Why) | 개인별 경로 안내로 이동 편의성 개선 | 횡단보도 사고 예방과 교통약자 보호 | 이동 편의성·접근성·재난 안전 문제를 함께 고려 |
| 새로움 (Novelty) | 기존 길 찾기 서비스의 발전형 | 기존 스마트 횡단보도의 확장형 | 물리적 이동 보조와 디지털 안내를 통합 |
| 실현 가능성 (How) | 높음. 기존 AI·지도·AR 기술 활용 가능 | 비교적 높음. 센서·신호 제어 기술 활용 가능 | 단계적 검증 필요. 기존 기술을 통합하되 안전성 확보가 중요 |
| 위험 요소 (Risk) | 위치정보 보호, AR 기기 의존성 | 신호 제어 오류, 교통 시스템 연계 문제 | 낙상·충돌, 설치 비용, 유지보수, 재난 시 전기 안전 |

### 3. 최종 선택 아이디어

**아이디어 C — SYMPATH 2050**

*사람을 이해하고, 사람에게 맞춰 변화하는 길*

**선정 이유**

아이디어 A와 B는 각각 개인별 길 안내와 횡단보도 안전 개선이라는 특정 문제에 집중한다. 반면 아이디어 C는 보행자의 이동 특성과 주변 환경을 함께 고려하고, 실제 보행 시설의 작동 방식까지 변화시킨다는 차별성이 있다.

또한 기존 무빙워크, 환경 센서, AR 안내 등의 기술을 활용하여 단계적으로 구현 가능성을 검토할 수 있다고 판단

다만 모듈 구동에 따른 낙상·충돌 위험과 설치 비용 등 해결 과제가 존재하므로, 실제 적용 전 안전성 검증이 필요

### 4. 팀의 최종 판단

AI의 제안을 그대로 수용하기보다 **기술의 필요성, 차별성, 실현 가능성, 위험 요소**를 기준으로 검토

최종적으로 보행 환경이 사람에게 맞춰 변화한다는 미래 비전을 가장 잘 표현할 수 있는 적응형 스마트 보행 인프라를 프로젝트 방향으로 선정

### 5. 향후 보완 방향

- 모듈형 보행 보조 장치의 안전한 작동 조건 구체화

- 스마트 글래스 미사용자를 위한 음성·모바일 안내 고려
- 침수 및 정전 상황에서 안전한 정지와 대피 기능 검토

### 2. 핵심 서비스

1. **모듈형 보행 보조:** 필요한 구간에서 저속 이동 모듈을 통해 보행 지원
